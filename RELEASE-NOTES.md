# Huntlog 0.6.4

## Correção

- Corrigido o reinício após uma atualização: a janela do Huntlog passa a abrir normalmente, em vez de ficar oculta em segundo plano.
- Mantidas todas as novidades da versão 0.6.3.

## Ao atualizar de uma versão anterior

O reinício dessa atualização ainda é executado pela versão antiga. Se aparecer "O Huntlog já está aberto" sem uma janela visível, abra o Gerenciador de Tarefas, selecione Huntlog, clique em Finalizar tarefa e abra o programa novamente. Isso pode acontecer uma última vez nessa transição; nas próximas atualizações feitas pela 0.6.4, o reinício já estará corrigido.

Seu histórico é preservado. Para instalar manualmente, extraia o ZIP inteiro para uma nova pasta e abra Huntlog.exe. Mantenha a pasta _internal junto do executável.
